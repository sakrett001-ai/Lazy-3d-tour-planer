# Проверки версии 0.1

Первая фиксация: 13 проверок доменной модели, экспорта, геометрии и сервера пройдены. Браузерные сценарии и визуальная доводка ещё проверяются; окончательные результаты будут записаны перед завершением версии.

`tests/project.test.mjs`: границы проёмов, состав экспортируемого пакета, действия получателя, поворот габаритов, удаление привязанного оборудования.

`tests/export.test.mjs`: синтаксис HTML и экранирование, размеры в адаптере, геометрия Three.js на CPU, совместимость варианта, локальный сервер, повреждённый GLB.

`tests/browser.mjs`: настоящий Chromium. CPU harness подменяет браузерные/WebGL API и проверяет геометрию; его прохождение не подтверждает отрисовку или качество света.
