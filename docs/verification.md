# Проверки версии 0.1

Проверено 31 октября 2026 года. **19 тестов Node и 12 браузерных сценариев пройдены.** Сборка автономного примера создаётся командой `npm run build`.

## Данные и геометрия

Проверены границы и пересечения проёмов; состав экспортируемого каталога и зависимостей; права получателя; сохранность исходного документа при отклонённой операции; совместимость варианта; корректность размеров/высот в адаптере.

Настоящая геометрия всех семи процедурных изделий проверена в Three.js на CPU: габарит, центр и нижняя отметка с допуском 0,05 см. Рейки остаются на поверхности стены. Для L-образной комнаты входная точка находится внутри полигона. GLB измеряется по вершинам и преобразованиям узлов; внешние URI и обязательный Draco отклоняются.

CPU harness подменяет браузерные/WebGL API только для измерения геометрии. Отрисовка проверяется отдельно настоящим браузером.

## Браузер

Chromium 153.0.8010.0, WebGL 2 через ANGLE/SwiftShader. Размеры экранов 1440 × 1000 и 390 × 844. [Машинный отчёт](browser-report.json).

Проверены: редактирование координат/поворота, перетаскивание, undo/redo, построение стены, оконный проём и отказ при неверном размере, температура и высота светильника, импорт текстурированного GLB, сохранение JSON, обзор/прогулка, обновление окружения при смене режима света, автономный экспорт с выбранным каталогом, расстановка получателем, импорт допустимого/отказ недопустимого варианта, повторная выгрузка HTML, мобильные библиотека/свойства/открытие файла и восстановление нового проекта после reload.

Для автономного HTML HTTP(S)-запросы блокировались тестом: **0 внешних запросов**. Проверяется наличие фактической текстуры GLB, а не только успешная загрузка модели. Необработанных ошибок страницы — **0**.

В диагностической сцене с тестовым GLB зафиксированы 56 вызовов отрисовки и 13 720 треугольников. Это описание одной тестовой сцены, не замер FPS и не гарантия производительности на реальном телефоне.

## Визуальная проверка и границы

Просмотрены [редактор](images/editor.png), обзор 3D, прогулка, получательский план, [свойства на узком экране](images/mobile.png). Независимый финальный просмотр выявил четыре ошибки; исправления повторно проверены: офлайн-текстуры GLB, восстановление авторского проекта, вход в вогнутую комнату и открытие JSON на телефоне.

Не проверялись физическое мобильное устройство, сложные сторонние производственные каталоги, предельные 1000 экземпляров, инженерные нормы, расчёт люкс и фотореализм относительно фотографии. Blender/Cycles-утилиты перенесены как отдельный конвейер; массовая ИИ-генерация/пересборка моделей не заявляется.
