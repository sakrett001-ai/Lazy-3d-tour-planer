# Проверка станции v0.2

Дата: 31 октября 2026.

## Выполнено

- `npm test`: 24 успешных проверки. Включают самостоятельный авторский HTML, сохранение полного каталога, ограничение пакета получателя, габариты семи встроенных изделий, проёмы, импорт GLB, внутренние размеры нового помещения, независимость снимков, JSON roundtrip, SVG и CSV.
- `npm run build`: создан `web/index.html` и два демонстрационных экспорта.
- В облачном Chrome через штатный Sites preview открыт именно автономный HTML, без API-сервера.
- Создано помещение 520 × 380 см; площадь 19,8 м², стены толщиной 15 см вынесены за внутренний контур.
- Диван размещён в центре; создан снимок. После изменения X с 260 на 150 открытие снимка вернуло центральную расстановку.
- Книга `lazy-station/1` скачана и повторно открыта через выбор файла. Проверены название, один вариант и исходный X=260 в сохранённом JSON.
- Отображены SVG-лист и ведомость; CSV скачан. Поправлено размещение обозначений помещений в SVG, чтобы уменьшить наложение на мебель.

## Границы проверки

Облачный Chrome не смог создать WebGL-контекст. Интерфейс корректно сообщил об ошибке и сохранил доступ к плану. Текущее 3D-изображение в этой среде не проверено; CPU-сборка геометрии проходит. Проверки WebGL предыдущей версии описаны отдельно в `verification.md` и не выдаются за повторную проверку v0.2.

Расширение облачного браузера не завершило скачивание HTML/SVG (тайм-аут события download; JSON/CSV скачаны). Содержимое самостоятельного HTML проверено компилятором JS и запуском той же статической сборки по HTTP; SVG отображён в интерфейсе и проверен модульными тестами. Открытие через `file://`, загрузка HTML/SVG на обычном устройстве и мобильный WebGL требуют отдельной проверки. Настройки браузера и движок для обхода ограничений тестовой среды не изменялись.

Сценарий `tests/browser.mjs` обновлён под мастер нового проекта, но полный Playwright-прогон v0.2 в этой среде не запускался. Отчёт из v0.1 остаётся историческим.
