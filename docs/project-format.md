# Формат проекта и каталогов

Полный пример: [studio.json](../examples/studio.json).

| Поле | Содержание |
| --- | --- |
| `schema`, `mode`, `units` | `lazy-tour/1`, `author`/`recipient`, `cm` |
| `meta` | ID, название, версия |
| `walls` | Концы a/b, толщина, высота, материал, проёмы |
| `rooms` | Название, простой многоугольник пола, материал |
| `instances` | ID экземпляра, assetId изделия, x/y, z от пола, поворот |
| `fixtures` | Свет, розетки, выключатели; координаты либо привязка к стене |
| `materials` | Тип, цвет, roughness, scaleCm, reliefMm и ссылки на карты |
| `catalogs` | Группы изделий с ID и габаритами |
| `assets` | ID файла → `{mime, data}`; data — base64 |
| `selection` | Изделия и отделки для выгрузки |
| `lighting` | Режим, температура/сила дневного света, экспозиция |
| `policy` | Разрешения furniture и finishes |

Проём задаётся расстоянием от начала стены offset, шириной, высотой и отметкой низа sill. Для двери sill=0. Направление стены определяет начало проёма и стороны оборудования.

`size` изделия: `[ширина, глубина, высота]`. x/y экземпляра — центр габарита, z — отметка нижней точки. Положительный поворот совпадает с 2D-планом. GLB измеряется из геометрии без растяжения.

## Импорт каталога

Объект `lazy-catalog/1` содержит `catalog`, `materials`, `assets`; см. [catalog-template.json](../examples/catalog-template.json). ID уникальны относительно открытого проекта. Существующий материал можно использовать по ID без повторного добавления.

GLB-изделие имеет `kind: "glb"`, `model: "file-id"` и измеренный size. Файл расположен в assets с MIME `model/gltf-binary`. Кнопка «Добавить модель GLB» сама измеряет и упаковывает файл.

GLB: внутренние буферы и изображения, без внешних URI, обязательных расширений, Draco/Meshopt и скелета. Из Blender экспортируйте GLB с применёнными модификаторами и упакованными изображениями; единицы glTF — метры.

Карты материала: texture — sRGB; normal — OpenGL Y+, линейная; roughnessMap — линейная, зелёный канал. color умножается на цветовую карту. Для исходных цветов изображения используйте белый. scaleCm задаёт повторение рисунка.

## Пакет и вариант

Состав экспорта: выбранные ∪ расставленные изделия → необходимые материалы и файлы, плюс поверхности помещения и выбранные отделки. Остальные файлы не передаются. Получатель может повторно выгрузить HTML в пределах того же пакета.

«Сохранить проект» в режиме получателя создаёт `*-variant.json`. При восстановлении геометрия, оборудование, материалы и каталоги должны соответствовать исходному пакету. Принимаются расстановка, свет и разрешённые изменения отделки.
