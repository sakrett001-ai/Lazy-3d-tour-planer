# Станция дизайна интерьера · v0.2

`web/index.html` — готовая авторская станция в одном файле. Скачайте файл через GitHub (Download raw file) и откройте браузером. Node.js, установка зависимостей и локальный сервер для этой версии не нужны. Исходники остаются в `app/`, `src/`, `engine/`; `npm run build` пересобирает HTML.

Веб-ссылка находится в начале README. Это отдельная публикация Sites; репозиторий хранит исходники и точно такую же автономную сборку. Публикация по умолчанию доступна владельцу через его аккаунт ChatGPT. Скачанный HTML можно передать коллегам; он не требует входа. GitHub показывает HTML как код, поэтому ссылка на файл репозитория сама по себе не запускает приложение.

## Рабочий процесс

1. «Новый проект»: название, внутренние размеры, высота, толщина стен; по желанию входная дверь и окно. Каталоги и материалы текущего проекта сохраняются.
2. Постройте перегородки, добавьте помещения, проёмы, свет и электроустановочные изделия. Расставьте мебель, загрузите модели GLB и карты материалов.
3. «Варианты»: сохраните до 12 независимых снимков. Каждый включает архитектуру, расстановку, материалы, свет и каталоги. Открытие снимка можно отменить.
4. «Лист плана»: векторный SVG с обозначениями и масштабной линейкой, список мебели CSV, самостоятельный HTML-редактор с текущим проектом.
5. «Выгрузить тур»: HTML получателя с выбранным каталогом и разрешёнными действиями. Другие варианты туда не попадают.

## Файлы

| Файл | Что содержит | Как открыть |
| --- | --- | --- |
| `web/index.html` | Редактор и нейтральный пример | Скачать и открыть браузером |
| `*-project.json` | Текущий авторский проект | «Открыть» в станции |
| `*-design.lazy.json` | Текущий проект и все сохранённые варианты, `lazy-station/1` | «Открыть» в станции |
| `*-tour.html` | Тур получателя и ограниченный пакет | Открыть браузером |
| `*-plan.svg` | Векторный эскиз и легенда | Браузер, графический редактор, печать |
| `*-furniture.csv` | Количество и размеры расставленных изделий | Табличный редактор; UTF-8, разделитель `;` |

Автосохранение привязано к браузеру и адресу страницы. Оно не синхронизируется между устройствами. Скачивайте проект со всеми вариантами для переноса и резервной копии; обычное «Сохранить проект» сохраняет текущий вариант. При недостатке памяти интерфейс предлагает сохранить файл. Книга ограничена 72 МБ; модели повторяются в независимых снимках.

Размеры в мастере — чистые внутренние. Стены размещаются снаружи контура пола. Подписи длин на плане — размеры по осям стен. Площадь считается по контурам пола без вычитания пересекающихся комнат. SVG является эскизом для обсуждения, а не рабочей строительной документацией.

3D требует WebGL. Материалы, свет и геометрия используют существующий движок; v0.2 меняет упаковку, проектный процесс и выпуск планировочных материалов. Нового трассировщика, оптимизации всех сторонних моделей или генерации StableGen в этой версии нет.
