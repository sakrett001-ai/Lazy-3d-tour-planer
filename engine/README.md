# Интерьерный движок

runtime/core-head.js, catalog.js, core-tail.js — общее ядро. planner.js — новый адаптер Lazy. Three.js r160 и GLTF-модули сохраняют MIT-лицензию.

Из корня репозитория: npm start запускает конструктор; npm run build создаёт нейтральный автономный тур с процедурными материалами.

build.mjs, make.py, tools/ и projects/template-kabinet/ сохраняют прежний конвейер interiors-engine/1. Свои карты нужно передать через textures/ проекта. Прежние клиентские изображения не включены; сборщик сообщает об отсутствии карт. Такой отчёт не означает визуально готовый тур.

Экспорт геометрии, чертежей и Blender/Cycles требует отдельных Python-зависимостей. Проверки новой версии описаны в [docs/verification.md](../docs/verification.md). Результаты прежних проектов не являются проверкой нового редактора.
